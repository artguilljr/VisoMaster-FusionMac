VisoMaster Fusion Mac launcher with custom icon

Unzip, then copy VisoMaster Fusion.app into Applications to replace your previous launcher app. Open the app to start your existing installation at /Applications/visomaster-fusion using the existing /opt/miniconda3/envs/visomaster-mac Python environment. No program files or models are replaced.

VisoMaster Fusion.command is the Terminal launcher with live logs. The app enables the previously approved CoreML settings; model profiling remains off. Startup errors are logged at ~/Library/Logs/VisoMasterFusion/launcher.log.

VisoMaster Fusion Icon.png is a copy of the icon for your own use. If macOS shows the previous Dock icon after replacing the launcher, remove the old Dock shortcut and drag in the newly copied app.
